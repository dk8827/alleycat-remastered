# Component licensing

This repository contains components with different origins. There is no single blanket license covering all of them.

| Component | Status |
| --- | --- |
| Original Alley Cat program and data in `game/asm/`, and output derived from them | Original game material; no redistribution license is granted by this repository |
| DOSBox-derived BIOS font in `engine/bios-font.js` | GPL-2.0-or-later; see the file header and `licenses/DOSBox-font-GPL-2.0.txt` |
| Project-specific runtime, renderer, interface, tools, and tests | A distribution license has not yet been selected |
| Generated HD paintings | No separate asset reuse license has yet been selected |

Third-party build dependencies retain their own licenses. The presence of game material in this repository does not imply that it is public domain.
